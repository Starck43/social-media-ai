# P21-T08 — Model configuration consolidation and legacy cleanup

Registry: [ROADMAP](../../ROADMAP.md); parent: [P21](../phases/p21-ai-operations.md).

## Goal

Consolidate model/provider/agent settings around the existing catalog and one
resolution contract, removing accidental duplication without erasing historical
accounting evidence or inventing a generic `agents` table.

## Dependencies and owner gates

- Depends on P21-T02 and its resolution matrix; use P21-T07 findings where model
  parameters affect tool safety.
- Deleting `tenants.agent_model`, changing environment precedence, changing public
  model schemas, or adding/removing columns is irreversible or user-visible;
  obtain owner approval and define a migration/rollback before implementation.

## Steps

1. Document canonical sources and precedence for provider, model, tenant/scenario,
   temperature, max tokens, response format and modality.
2. Replace hardcoded call-site defaults with typed shared resolution only where
   behavior is covered and compatibility is explicit.
3. Keep model/provider strings in immutable receipts and historical analytics as
   evidence snapshots; do not normalize them away.
4. Validate any modality-specific parameters at the application boundary; add
   JSONB only for a demonstrated, versioned contract rather than speculative keys.
5. Remove dead/legacy settings only after usage search, migration rehearsal and
   owner approval.

## Acceptance

- A resolution table and focused tests cover scenario → tenant → model defaults →
  eligible fallback, with no cross-owner or cross-tier selection.
- `temperature`/`max_tokens` precedence is consistent across chat, analysis,
  digest, learning and tool calls, or documented exceptions remain explicit.
- Fallback never bypasses payer, capability, permission or budget denial.
- Historical evidence and public API compatibility remain intact until consumers
  migrate.
- Any migration has a placeholder revision, isolated cycle, rollback decision and
  exact integration evidence; no table rename is assumed.
