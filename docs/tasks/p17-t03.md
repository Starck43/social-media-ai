## Goal

Users ask “покажи остатки товара X” and get a verified table.

## Baseline

- Typed LLM output contracts (P5), chat tool registry (P11-T09).

## Plan

1. LLM converts the question into the typed query plan of T02 (JSON schema), validated against allowlisted metadata; ambiguous items → clarification question; raw query text is never executed (R-07).
2. Show the interpreted plan before execution; execute read-only; format as table, optional chart (inline charts) and short summary with figures taken only from results.
3. Export to XLSX and PDF (server-side, bounded rows); audit exports.
4. Model `onec_query_history` (tenant, user, connection, question encrypted, plan JSON, row count, duration); reuse a past plan.
5. Chat tool `onec_query`; API `POST /api/v1/integrations/1c/query`, `GET …/query/history`.
