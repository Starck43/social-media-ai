# P12-T03 — Knowledge & Documents workspace with ACL-aware citations (`/app/knowledge`, `/app/documents`)

Registry: [ROADMAP](../../ROADMAP.md#p12); current status/owner/dialogue live there.

## Scope and acceptance

Build the `/app/knowledge` and `/app/documents` workspace for searching approved folders/mailboxes and inspecting versioned documents:
- Enforce tenant, actor, and source ACL filtering before retrieval or model context assembly; revoked source access immediately invalidates cached visibility.
- Render verifiable provenance references on every snippet and answer (`source ID`, `document version/hash`, `page/cell/message anchor`, `sync timestamp`) alongside explicit extraction/OCR/freshness limitations.
- Track document correspondence versions where any content edit automatically invalidates prior approval records (`edits invalidate approval`).

Accept with cross-tenant ACL isolation tests, provenance citation formatting checks, and version-invalidation tests.
