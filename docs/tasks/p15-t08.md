## Plan

1. `POST /api/v1/communication/threads/{id}/reply` creates an outbox draft bound to the thread's channel/connection/recipient; user may switch channel explicitly.
2. Email replies set `In-Reply-To`/`References`; messenger replies reference the chat.
3. Approval per item (default) with an optional per-workspace ‘reply without second confirmation’ policy only for transactional replies, if the owner enables it.
4. Sent reply appears in the thread after provider confirmation.
