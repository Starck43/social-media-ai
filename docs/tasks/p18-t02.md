## Goal

Server side of pairing and federated search.

## Baseline

- P12-T12 file catalog, admission and evidence contracts (PR #327).

## Plan

1. Model `local_connectors` (tenant, owner, device name, fingerprint, platform, version, state, last seen, revoked at) and pairing codes.
2. Endpoints `POST /api/v1/files/connectors/register` (pairing), `GET /api/v1/files/connectors`, `DELETE …/{id}` (revoke), WebSocket endpoint for connector sessions owned by the API process with bounded connections.
3. `POST /api/v1/files/search`: authorizes actor, picks the user's online connectors, fans out with timeout, merges ranked results (metadata + snippets) into the P12-T12 evidence format with `data_boundary=local_only` unless the user marks a folder `company`.
4. Chat integration: local results only usable by local-only routes per P12-T11; otherwise show references without content.
