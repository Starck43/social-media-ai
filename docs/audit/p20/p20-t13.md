## What was accepted

Bounded usability hardening that preserves colors, typography, navigation, route,
permission and confirmation contracts:

- model pickers gain ArrowUp/Down, Home/End, selected-option focus and Escape
  hand-off, one key press per move, hidden/inert/disabled options excluded;
- shared shell dialogs and the chat dock have a single claim/release owner for scroll
  lock, `aria-expanded` and focus; `app:shell-dialog-open` covers the missing native
  `show` event and `open`-attribute observation covers a reused dialog that never
  fires a second `close`;
- the task add modal gets unique explicit `for`/`id` associations (21 pairs, no
  duplicates) with unchanged field names, Alpine bindings and submit routes;
- the agent launcher sits beside the notification bell, fixed chrome is reserved
  outside the content scrollport, and `viewport-fit=cover` enables safe-area insets.
