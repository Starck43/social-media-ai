## Granular Sub-Steps Inside This Task

1. **`T05.1` — Deterministic `Decimal` Comparison Engine (`app/services/cases/calculator.py`):** Normalize unit prices across currencies (`RUB`, `USD`, `EUR`), VAT modes (`with_vat`, `without_vat`), and pack sizes using `decimal.Decimal` (`ROUND_HALF_EVEN`). Preserve `None` as explicit `MISSING_PRICE` (never interpolate or call an LLM for math).
2. **`T05.2` — Version-Bound Case Approval (`app/services/cases/approvals.py`):** Bind product approval to `(actor_id, doc_version_hash, formula_version)`. Changing currency/VAT assumptions invalidates prior approval.
3. **`T05.3` — Wire Draft Template & Flip `ready=True`:** Connect `app/web/cases.py` -> `web/cases.html`.
