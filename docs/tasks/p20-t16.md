## Checks and decisions

In progress — not ready for merge or acceptance.

- A task-owned local PostgreSQL cluster, database and schema were created; migrations were applied. The app ran with scheduler and paid LLM dispatch disabled and a synthetic account, planner tasks, inbox metadata, agent schedules and chat history. No production data or external provider writes were used. After the run, the task-owned database was dropped (verified absent), the app and PostgreSQL were stopped, and ephemeral keys and browser state removed. Schema inventory snapshots were not captured for this disposable database.
- Today uses the actor-scoped planner service and tenant-scoped schedule manager; inbox filters preserve boundary and selection, normalise empty channel and report provider failures; the selected thread owns its triage panel. Planner list is grouped by due date; the calendar grid converts timestamp instants to the selected time zone. Task sources remain reachable as a secondary link.
- Route-backed local Chromium smoke: Today → planner, three task tabs and calendar navigation, inbox category filter and selected thread, and four chat context tabs passed. A synthetic planner task was completed successfully. `tests/browser/p20_t16_live_smoke.cjs` retains the non-destructive flow (requires a separately prepared local account/fixtures). Six surfaces returned HTTP 200 on 1440×900 and 390×844 in both themes, with no pageerror logged. These are smoke checks, not exhaustive visual acceptance.
- `tests/unit_web/test_p20_t16_work_regressions.py` and `tests/unit_web/test_p20_t07_today_home.py`: 16 passed. `tests/unit_web/test_template_autoescape.py` run isolated without conftest: 50 passed; the latter should also be revalidated under the project's current test policy. `node --check app/static/js/task-calendar.js` and `git diff --check` passed.
- The requested Personal Assistant audited the published dev baseline and reviewed two supplied adapter snippets, but could not access this local branch or independently run its tests. Its finding on filtering completed planner rows before the limit was corrected; the whole patch still needs independent review.
- Remaining: full visual comparison with the PDF and real states, responsive/tablet verification, chart/progress and draft flows with representative data, permission/tenant and pagination/time-zone regression tests, and a portable isolated seed/bootstrap. The inbox stores metadata only, not message bodies; no message content or coverage percentages were fabricated. The month grid only covers each provider's currently loaded page and labels this limitation. Do not report the redesign as complete.
