# P11-T24 — Reproduce schema guard objects in the metadata-built test schema

Registry: [ROADMAP](../../ROADMAP.md#p11). Parent: [P11](../phases/p11-structure.md) (navigation only).

## Scope, evidence and acceptance

**Evidence:** `scripts/setup_test_db.py` creates the test schema with
`Base.metadata.create_all`, then stamps the Alembic head. `create_all` creates
tables, columns and constraints but not the trigger functions and triggers from
migrations `0093` onward. The original gap was repaired in the live test schema,
but metadata rebuilds need to reproduce those guards.

**Change:** keep one reviewed source of guard DDL, apply it idempotently after
`create_all` for the resolved test schema, and bind each trigger to a function
in that same schema. The delivered code is reviewed; see the current diagnostic
in [audit/p11-t24.md](../audit/p11-t24.md).

**Acceptance:** a metadata-rebuilt schema carries the same guard objects as a
migrated schema; each trigger executes a function in its own schema; the
personal billing acceptance suite passes with no exclusions on the rebuilt
schema; applying the guard step twice is a no-op; and setup fails closed if
guard application fails. The migration drift test must be deterministic with
cold and warm bytecode caches and when run before and after other offline
manifest entries.

## Delivered source

Branch `fix/p11-t24-test-schema-guards`; original implementation source
`04429f7c`. `scripts/schema_guards.py` defines 26 trigger functions and 42
triggers with a schema placeholder and quoted target identifier.
`scripts/setup_test_db.py` applies them after `create_all`/stamp and stops if
application fails. `tests/tooling/test_p11_t24_schema_guards.py` derives the
inventory from migration AST without importing migrations.

The drift-test defect found after the earlier acceptance was corrected in
`9020f15c` and `95aa37b`, both integrated in the current `dev` candidate
`6b19f1717b2324a239f6783d11b3047462358185`. The corrected test selects the
upgrade-reachable 0103 helper call and fails closed for unresolved guard DDL.
See [audit diagnostic](../audit/p11-t24.md) for exact provenance and review.
