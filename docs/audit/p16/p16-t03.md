## Result

Google Calendar OAuth and two-way sync use explicit per-connection consent and
the selected calendar. Provider schedule, recurrence, attendees, and calendar
identity remain authoritative. Sync and task projections fail closed when the
source is unavailable; an unavailable calendar is never presented as empty or
served from a stale event cache. Multiple connections require an explicit
choice and never switch silently.

Writes use the existing command and approval ledgers, default off, with the
kill switch and authorization rechecked at execution. Conflicts and deletions
require per-item approval. Unknown write outcomes are not retried: a separately
approved, read-only `resolve_remote` observes the provider and records the
result. Calendar-owned task reminders use live source time; relative deadline
presets are refused and custom reminders defer when the source is unavailable.
Today reads live schedule data before deadline filtering and suppresses overdue
claims when it cannot read the source.
