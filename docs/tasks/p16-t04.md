## Goal

Same behaviour as Google for Yandex Calendar using its CalDAV interface (R-06).

## Baseline

- Calendar model and conflict handling from [P16-T03](p16-t03.md).

**Source authority (D24, [Q-21](../audit/q-21-source-authority.md)):** CalDAV decides events and
recurrence; we keep the link, consent and audit, and degrade to "source unavailable"
rather than to an empty calendar.

**Orchestration (D25, [Q-21](../audit/q-21-source-authority.md)):** a second calendar provider reuses the
same conflict record and per-item approval as [P16-T03](p16-t03.md); its external
identity goes to the shared source registry, not to a CalDAV-specific key.

**Overlap and choice (D26, [Q-21](../audit/q-21-source-authority.md)):** connecting Yandex
Calendar next to Google must prompt for a choice and must not replace the current
calendar by being connected later. Deleting the chosen provider leaves the overlap
without a choice, so the user is asked again.

**Registry introduction (D25 sequencing, [Q-21](../audit/q-21-source-authority.md#what-is-realistically-buildable-auditor-summary-2026-11-05)):** this is the first
second-consumer, so the shared source-object registry appears here. It is additive: one
table, one migration, written by `P16-T03`'s Google path and this task's CalDAV path.
`P16-T03`'s `(tenant_id, connection_id, external_id)` identity moves into it rather than
being copied; until this task lands the module-scoped key is the registry and nothing
else may depend on its shape. Rollback is deleting the table, not migrating data.

## Plan

1. Connection method: Yandex OAuth (CalDAV scope) or application password, fixed host `caldav.yandex.ru`, TLS pinned network policy.
2. Discovery (`PROPFIND` principal → calendar-home-set → calendars), selection per connection.
3. Incremental pull with `sync-collection` REPORT (fallback: ctag + ETag comparison); parse iCalendar (VEVENT, RRULE, timezones) with a maintained library.
4. Push with `PUT` + `If-Match`/`If-None-Match`; conflicts recorded as in T03.
5. API `POST /api/v1/calendar/connect/yandex`.
