## Findings

### [P1] Open files through a race-safe selected-root handle — local_connector/index.py:235–240

`resolve_relative()` checks names before `stat()`, `_content_hash()` and `_read()`
reopen the pathname normally. Replacing the validated file or an ancestor with an
outside symlink in that interval indexes data outside the selected root. Replacing
`x.txt` immediately after the real resolver returns reproduced a successful chunk
insert from the replacement target. Use platform-supported handle-relative,
no-follow reads and identity checks for both hashing and extraction; deny where
safe enforcement is unavailable. This is required by the accepted protocol.

### [P1] Pin the selected root identity across scans — local_connector/paths.py:106

Each scan re-canonicalizes the selected path with `resolve(strict=True)` instead
of retaining its approved directory identity. Rename the selected directory and
replace its old path with a symlink to another directory: the next scan silently
accepts that target as its new root. A separate reproduction indexed `leaked.txt`
from an outside directory with no errors. Bind selection to a verified directory
handle/identity and fail closed on replacement until the user selects again.

### [P1] Preserve user exclusions in every watcher scan — local_connector/watcher.py:33–34

`ConnectorRuntime.scan()` passes configured exclusions, but `start()` constructs a
watcher that calls `engine.scan(self.roots)` without them. With
`excluded_paths={'secret.txt'}`, the explicit runtime scan indexes zero files and
the watcher's next scan indexes `secret.txt`. Pass the same effective selection
and exclusions through initial, event and periodic scans.

### [P1] Implement the accepted device-side session protocol — local_connector/session.py:52–67

The only session API generates connector-originated requests with
`protocol_version`, string identities and optional signatures. The accepted
server sends signed `SearchRequest` commands with `version`, integer identities,
key ID, root scope, device/consent/policy epochs and resource limits, and waits
for typed device responses. There is no device receive/verify/dispatch path,
durable replay ledger or runtime transport wiring. Even injecting mTLS and a
signer cannot bridge this direction/schema mismatch. Implement the standalone
device half against the existing wire contract, including fail-closed verification
and replay handling; do not add server models or tables.

### [P1] Fence deletion against active indexing — local_connector/runtime.py:58–61

Confirmed deletion only executes SQL deletes while event and periodic scans remain
enabled. The next watcher scan immediately recreated the deleted entry; in-flight
work also has no generation fence preventing a late insert. Cancel/serialize
active indexing, persist a deletion generation and define an explicit restart
before claiming deletion completion. The task card's claimed deletion fence does
not exist in this revision.

### [P2] Prune only roots whose enumeration completed — local_connector/index.py:285–287

An unreadable directory or a denied symlink aborts the root iterator, then the
global `remove_paths_not_seen(seen)` deletes records for unvisited valid files.
After indexing `good.txt`, adding a lexically earlier `00-link.txt` reproduced
`deleted=1`, `errors=('root: PathSafetyError',)` and an empty index. Preserve the
previous records for failed/incomplete roots and prune only proven deletions.

### [P2] Apply UI folder changes to the runtime and watcher — local_connector/ui.py:88

`POST /folders` updates only `FolderSelection`; the engine reads
`config.selected_roots`, and the watcher holds an older tuple. A successful UI
change from root A to B leaves A selected for indexing and never scans B. Even
`runtime.select_roots()` does not replace a running watcher's tuple. Use one
selection-change operation that updates configuration and watcher atomically,
stops old-root work and removes out-of-selection results.

### [P2] Start HTTP request processing with the runtime — local_connector/runtime.py:44–46

`ConnectorRuntime.start()` starts the watcher and returns a listening socket from
`LocalStatusServer.start()`, but neither method starts `serve_forever()`. A GET
to the returned `/status` address times out. The isolated UI test starts its own
thread, while the runtime test only checks the port. Own the serving loop and its
shutdown in the runtime, and verify a real request through that entry point.
The advertised folder-selection UI also still needs a usable local user flow:
the root route currently returns JSON and there is no tray/form/token bootstrap.

### [P2] Restrict permissions on the derived-content cache — local_connector/index.py:45–48

The cache directory and database use default creation permissions. With umask
`022`, a source file restricted to `0600` is copied into a `0644` SQLite database
inside a `0755` directory. Other local accounts able to traverse the configured
cache parent can read content they could not read from its source. Create and
verify owner-private cache/database/sidecar permissions, with equivalent Windows
ACL handling; fail closed if that protection cannot be established.
