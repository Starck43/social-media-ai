existing handler, preserving UPDATE permission, owner-scoped lookup, 404 and
response/update semantics. No alias removal is scheduled; it needs a separately
approved breaking-change migration. Rollback: remove only the canonical decorator
and restore the previous API documentation; the legacy path remains operational.
