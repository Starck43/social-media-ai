## Finding

The assigned suite predated the cache-tariff v2 receipt contract: the
`cache_pricing` import was undeclared (eager app/bootstrap import risk),
explicit free v2 lacked zero cache-rate evidence, resolver replay used bare
model-name keys instead of `(model_row_id, provider_name, model_id)`, and
one timeout expectation required `messages` inside the failure request
field, contradicting the P10-T06 safe envelope. The card's historical
missing-unit diagnosis was incomplete: `price_attempt` already defaults an
absent legacy-double unit to 1000 and rejects explicit NULL/invalid v2
units; the receipt stores the unit explicitly.

## Solution

Tests-only reconciliation of
`tests/security/test_analysis_dispatch_identity.py`; no production,
billing policy, `llm_client.py` or other suite changed. Actual cache
pricing, catalog context, tenant context, personal dispatch gate, clients
and journal run via module-local source imports; storage/settings alone
are doubled, undeclared `app.*` imports, sockets and DNS are refused, and
post-test `sys.modules` hygiene is asserted. The timeout expectation is
replaced by the exact safe request-field allowlist with absence of
`messages`/`prompt`/`endpoint` for all clients. Nine new methods cover
explicit 1K/1M unit snapshots, per-million cache rates, missing cache
evidence (UNDEFINED, not invented zero), unknown custom format, invalid
units, absent-unit legacy compatibility, v1 semantics, free-v2
completeness and actual catalog-ownership refusal before dispatch. All 34
original methods are retained.
