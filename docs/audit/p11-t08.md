## Delivered contract and review

The [API compatibility inventory](../api-route-contract.md) records mounted
route/auth groups, hidden legacy probes, existing error shapes, list bounds,
expensive operations, version/alias migration policy and proposed error/OpenAPI
snapshot contracts. Q-10's doubled credentials route and existing notification
aliases are retained. Public allow-list entries remain exact normalized paths;
API and operator classification now check complete path segments.

Source/task/scenario/credential and personal LLM catalog list queries use bounded
pagination (default 50, maximum 100; nonnegative offset); user bounds reject zero
and roles keep their existing page envelope. Catalog totals count filtered rows
before pagination. Response shapes remain compatible, but callers must page to
retrieve more than one page. Request correlation validates a bounded ASCII
X-Request-ID or generates one, retains it in request state and echoes it for auth
refusals and normal responses. The standard non-debug 500 handler retains the
generic body, logs only exception type/correlation ID and echoes that ID.

Keyed typed task-plan launches enforce actor concurrency 3 and workspace
concurrency min(20, configured task ceiling). PostgreSQL existing job rows and
the workspace admission lock are the consistent multi-process store. The counts
and job insertion share one transaction. Existing receipts replay before quota;
different canonical payload reuse retains the old conflict status. Overload
returns 429 and Retry-After 30. An inactive saved draft may remain and is retried
with the same key. P11-T08 adds no Redis, schema migration or broad generic idempotency layer.
The durable key lasts for its task, survives job pruning, and preserves pending,
unknown and unavailable outcomes instead of claiming successful external effects.
Legacy direct runs/scheduled launches keep their existing admission policies.

Review corrected an initial non-atomic precheck: task creation committed before
actual job admission, so it could not enforce concurrent active-job counts.
The final quota moved into AgentTaskManager._admit_task_run under the existing
workspace lock. DB tests then found two .in__ typos, corrected to SQLAlchemy .in_
in `c1f834abd1713151f9c78996b3eb9c021bf066de`.
