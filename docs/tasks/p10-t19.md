The dominant single cause is **the autouse `operator_permission_scope()` in
`tests/conftest.py`** (added 2026-10-09, `4244b51`, "legacy tests already model
the operator surface"). Every test in the repository therefore runs with
`_operator_grant=True`, and `has_permission`/`has_role` return `True` before any
identity check — including inside `permission_scope(...)`, whose docstring says
an interactive scope *clears* inherited grants. Eight suites encode the
fail-closed contract and cannot see it. This is a harness-level design question
(where does the grant apply, and how do permission tests opt out), not 20
independent test bugs, and the current pop is a lie the whole repository tells.
