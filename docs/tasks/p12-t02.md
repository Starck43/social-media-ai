## Architectural Decisions

1. **Extend `Platform` (`platforms`), Do NOT Rename:**
   - Building on `Q-16` (`app/models/collection/platform.py` + `app/services/social/platform_config.py`), keep the `Platform` model name intact and extend `PlatformType` (`app/types/enums/platform_types.py`) and `_BOOTSTRAP` (`app/services/social/platform_config.py`) with:
     - `vk`, `telegram`, `email`, `bitrix24`, `onec`, `yandex_disk`, `mailru_cloud`, `local_gateway`.
2. **Per-User, Per-Workspace Credentials (`UserCredential` + `tenant_id`):**
   - Add nullable `tenant_id` (`ForeignKey("tenants.id", ondelete="CASCADE")`) to `app/models/identity/user_credential.py` so each user configures connectors isolated to their active workspace (`tenant_id = current_tenant.id`).
   - Store encrypted tokens/app passwords in `secret_encrypted` and non-secret parameters (`portal_url`, `odata_url`, `imap_host`, `account_login`) in `UserCredential.meta`.
3. **Cloud Drive & Document Connection Flow (`Source` with `SourceType.DRIVE_FOLDER`):**
   - Add `DRIVE_FOLDER = ("drive_folder", "Папка облачного диска")` to `SourceType`.
   - Selected folders on Yandex Disk (`https://cloud-api.yandex.net/v1/disk/resources`) or Mail.ru Cloud WebDAV (`https://webdav.cloud.mail.ru`) are saved as `Source(platform_id=..., source_type=SourceType.DRIVE_FOLDER, external_id="disk:/Договоры 2026", params={"credential_id": cred.id, "allowed_extensions": [".pdf", ".docx", ".xlsx"]})`.

## Granular Sub-Steps Inside This Task

1. **`T02.1` — Enums & Bootstrap Catalog:** Extend `PlatformType`, `SourceType.DRIVE_FOLDER`, and `_BOOTSTRAP` in `app/services/social/platform_config.py`.

4. **`T02.4` — Wire `/app/settings?tab=connections` Template:** Pass `workspace_connectors` into `app/web/templates/web/settings.html` (`tab == "connections"`) and add unit tests in `tests/unit_web/test_p12_t02_settings_connectors.py`.

## Jinja2 Template Context Contract (`app/web/templates/web/settings.html`)

When `tab == "connections"`, `app/web/settings.py` supplies:
- `connections: list[dict]` (existing social connection cards)
- `workspace_connectors: list[dict]` with keys: `id`, `name`, `platform_type`, `category_label`, `auth_protocol`, `credential_owner`, `data_boundary`, `capabilities`, `write_capabilities`, `mounted_folders`, `watermark`, `health_status`, `health_diagnostic`.
