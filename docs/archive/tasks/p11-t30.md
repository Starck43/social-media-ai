# P11-T30 — Test-schema bootstrap must carry every migration-only trigger

Registry: [ROADMAP](../../../ROADMAP.md#p11); current status/owner/dialogue live there.
Parent: [P11](../../phases/p11-structure.md)

- **Priority / complexity:** `P2` · `C2`
- **Depends on:** nothing
- **Owner decisions:** none

## Problem

`scripts/setup_test_db.py` builds a fresh schema from `Base.metadata.create_all`, which emits no
trigger and no trigger function, and then applies the guard objects kept in
`scripts/schema_guards.py`. That module is missing four objects that exist only in migration
history:

- `bump_contact_pii_marker` plus its `contact_pii_marker` trigger on every table migration 0130
  and its followers attach it to;
- `detach_document_contact` plus `document_detach_contact` (0142);
- `detach_document_case_evidence` plus `document_detach_case_evidence` (0142);
- `set_document_current_revision` plus `document_revision_current` (0142).

Consequence: a schema created through the bootstrap path has no `pii_updated_at` marker bump and
no `current_revision_id` pointer maintenance. Document updates, restores and history pages fail on
such a schema, and PII mutation tracking silently does not run. `test_schema` is unaffected
because it was built by migrations, which is exactly why the gap stayed invisible.

The drift test `tests/tooling/test_p11_t24_schema_guards.py` is supposed to catch this, but two of
its resolver failures abort before comparison: `for table in TABLES` in 0130/0139 is not followed
to the module-level constant, so the guard-DDL scan "cannot resolve migration call arguments".

## Plan

1. Teach the drift test to follow a `for <name> in <CONSTANT>` loop to a module-level literal tuple.
2. Add the four functions and their triggers to `scripts/schema_guards.py`, matching the final
   post-migration state.
3. Prove it by building a scratch schema through `create_all` plus the guards and diffing its
   trigger and function inventory against `test_schema` (which was built by migrations): the
   difference must be empty.
4. Keep the guard drift test green so the next omission fails immediately.

## Owned paths
