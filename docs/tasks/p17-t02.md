- **Depends on:** [P17-T01 accepted](../audit/p17-t01.md)
- **Owner decisions:** none. **Recorded constraint:** the shared 1C provider budget keeps one account per active connection per workspace and fails closed with `connection_unavailable` for a second connection on the same endpoint and login; do not widen or bypass it silently ([policy](../audit/p17-t01.md#recorded-budget-policy)).

## Goal

Typed, bounded reads of reference data, documents and register balances.

## Baseline

- Deterministic Decimal arithmetic in cases (P12-T05).

## Plan

1. Metadata catalog from `$metadata`: entity sets (`Catalog_*`, `Document_*`, `AccumulationRegister_*`, `InformationRegister_*`), fields and types; admin allowlist per connection.
2. Query builder producing OData `$filter`/`$select`/`$orderby`/`$top`/`$skip` from a typed plan (entity, fields, filters by date/counterparty/item, period); register balances via `Balance(Period=…)` functions.
3. Hard limits: max 1000 rows per request, pagination tokens, 30 s timeout; monetary values as Decimal with currency.
4. Store nothing by default except query history metadata; results returned to the caller and optionally cached per request with TTL.
