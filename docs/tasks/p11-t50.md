- Format `tests/cli/test_interface_contract_audit.py` and record the exact file in the
  formatting baseline only if the reformat is deliberately deferred; prefer the
  reformat.
- Triage the eight candidates one by one (synthetic fixture literals and
  documentation hashes, expected) and extend `.ci/secret-baseline.json` with a
  rationale per entry, exactly as P11-T48 did for the previous ten. Never suppress by
  loosening scanner filters or filters, and never record a secret value.
- Accept when `scripts.ci.checks` exits 0 on the merged revision with
  `New secret candidate` absent and the formatting section clean, plus a green
  `scripts.ci.run_offline` (169 or more passed).
