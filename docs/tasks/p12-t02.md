## Scope and acceptance

Extend `/app/settings?tab=connections` («Мои подключения и коннекторы»), the `Platform` / `PlatformType` catalog, and `UserCredential` so every user in their workspace configures their own external connectors alongside social auth without creating a separate sidebar route:
- **Keep the `Platform` (`platforms`) model name** to preserve foreign keys (`sources.platform_id`), `user_credentials.platform`, SQLAdmin views, and migrations; extend `PlatformType` and `_BOOTSTRAP` in `app/services/social/platform_config.py` with categorized external services:
  - Social & Messengers: `vk` (VK OAuth / token), `telegram` (MTProto session / Bot)
  - Mail: `email` (IMAP/SMTP TLS with app password)
  - CRM & ERP: `bitrix24` (portal webhook / OAuth 2.0), `onec` (1C OData REST / HTTP service)
  - Cloud Drives & Document Stores: `yandex_disk` (Yandex Disk OAuth REST API), `mailru_cloud` (Mail.ru Cloud WebDAV + app password), `nextcloud` (WebDAV)
  - Local Gateway: `local_gateway` (paired outbound mTLS device)
- **Workspace-scoped user credentials**: add optional `tenant_id` to `user_credentials` (`NULL` = personal cross-workspace secret; `tenant_id = X` = connector configured by this user specifically for workspace `X`), storing non-secret endpoint metadata (`portal_url`, `odata_url`, `imap_host`, `mounted_folders`, `payer_binding`, `watermark`) in `meta` and encrypting secrets via Fernet (`CREDENTIALS_KEY`).
- **Cloud Drive & Document mounting flow (`yandex_disk`, `mailru_cloud`)**:
  1. User authorizes Yandex Disk (OAuth `cloud_api:disk.read`) or Mail.ru Cloud (WebDAV app password) in `/app/settings?tab=connections`.
  2. User selects specific allowed folders on the drive (e.g. `/Договоры 2026`, `/КП Поставщиков`), which are persisted as `Source` rows (`source_type = DRIVE_FOLDER`, `platform_id = yandex_disk | mailru_cloud`, `params = {"credential_id": ..., "allowed_extensions": [".pdf", ".docx", ".xlsx"], "max_file_size_mb": 25}`).
  3. Background worker polls folder metadata (`GET /v1/disk/resources` SHA-256/modified for Yandex Disk; `PROPFIND` ETag/lastmodified for Mail.ru WebDAV), downloads only changed files, parses pages/XLSX cells deterministically, and indexes versioned documents into `/app/knowledge` and `/app/documents`.
- Surface redacted health/reauth/revocation diagnostics, read vs. outbound-write capability badges, and explicit modality/boundary disclaimers inside `/app/settings?tab=connections`.
