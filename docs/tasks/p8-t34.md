## Deferred scope

No non-social connector work is in the current social/VK milestone. This card
preserves the future direction, not an instruction to build every listed
connector. After the social milestone, select one bounded, demand-backed pilot
from files/folders, one external service, or an explicitly paired local/private
network gateway. The chosen gateway is an authorized execution route, never
arbitrary shell or network access.

Before implementation, the selected pilot must name its connector operations,
connection/grant owner, allowed sources/targets, data-transfer and retention
boundary, tenant permissions, plan entitlements, quotas, provenance, failure and
revocation behavior. Keep reads separate from transformations and approved
writes; provide focused mocked cross-tenant/outage/retry checks. Do not assume
one generic schema or unrestricted adapter covers every future connector.

Status stays DEFERRED until the owner selects a pilot and schedules it into a
future phase; it does not block completion of the current social P8 milestone.
