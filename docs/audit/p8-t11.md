**Verdict:** ACCEPT · 2026-10-27 · independent acceptance by OpenCode —
accepted at head `f9169b6a` (PR #252), integrated into dev as merge

## Scope accepted

A personal-bell aggregate signal for incomplete deliveries built strictly from
existing outcome receipts (job + digest): owner/admin see the workspace
aggregate, manager/viewer see only their own initiated jobs
(`initiated_by_user_id` filter), non-members are denied, payloads stay
redacted, workspace switching is CSRF-guarded and a plain
`GET /app/notifications/delivery/{id}` never switches spaces; revoked rows
return 404 and an unavailable signal is not rendered as "empty".
