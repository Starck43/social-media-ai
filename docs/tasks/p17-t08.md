## Goal

Halve the provider requests per 1C question and stop advertising history states that are never written.

## Baseline

- [P17-T03 accepted](../audit/p17-t03.md) · findings F6–F7.

## Plan

1. **F6:** cache the `$metadata` catalog per connection, keyed by the connection's `metadata_sha256`, with a bounded TTL, so one question costs one provider request instead of two. The 1C policy allows 10 requests per 60 s (`rate=10, burst=10, window=60`); today a question spends two of them.
2. **F7:** align the `onec_query_history` status set with what the service writes (`executed`, `exported`) — either write the missing states meaningfully or drop them from the model, the migration and the check constraint.
