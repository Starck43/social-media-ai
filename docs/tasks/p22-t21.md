# P22-T21 — Budget and compact agent conversation context

[Phase](../phases/p22-universal-tasks.md) · [Task conversations](../product/UNIVERSAL_TASKS.md#task-conversations) · [Agent runtime](../agent/AGENT.md#web-chat)

Define a shared runtime budget for main and task chats. The existing `AGENT_HISTORY_LIMIT` limits replay by record count. Preserve the original transcript and serve it independently of model input.

- Enforce a per-attempt total input budget that covers system prompt, tool schemas, message and attachment content, tool results and a reserve for output. Recheck after a tool round and when the model changes. If a mandatory payload alone exceeds the budget, stop before provider invocation with a clear reason.
- When the budget threshold is reached, compact older eligible turns into an actor- and workspace-scoped session summary and checkpoint. Keep recent turns, complete tool-call/result groups and pending confirmations intact. Prevent concurrent or repeated compaction from skipping or duplicating history. Keep the existing data boundary, billing and tool authorization checks.
- Accept with long tools/attachments, repeat compaction, concurrent turns, provider fallback, workspace switching and corrupted or stale summaries. Check that old transcript pages still return original records.
