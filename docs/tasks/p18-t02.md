## Goal

Server side of pairing and federated search.

## Baseline

- P12-T12 file catalog, admission and evidence contracts (PR #327).

## Plan

1. Model `local_connectors` (tenant, owner, device name, fingerprint, platform, version, state, last seen, revoked at) and pairing codes.
2. Endpoints `POST /api/v1/files/connectors/register` (pairing), `GET /api/v1/files/connectors`, `DELETE …/{id}` (revoke), WebSocket endpoint for connector sessions owned by the API process with bounded connections.
3. `POST /api/v1/files/search`: authorizes actor, picks the user's online connectors, fans out with timeout, merges ranked results (metadata + snippets) into the P12-T12 evidence format with `data_boundary=local_only` unless the user marks a folder `company`.
4. Chat integration: local results only usable by local-only routes per P12-T11; otherwise show references without content.

## Implementation decisions / security gates

- The implementation currently uses a closed UTF-8 JSON envelope with ASCII schema keys, sorted keys/no floats/duplicate-key rejection; Ed25519 signatures; explicitly configured CA/signer and short-lived X.509 client certificates; and the authenticated ASGI TLS extension (never public identity headers). These are implementation choices, not an owner resolution of Q-19 R-2. Private keys are not generated as deployment defaults or committed.
- Replay ledger: durable request ID + digest per device, 24-hour window, bounded capacity, no payload/result persistence; uncertain or missing prior outcomes return unknown/deny, never a blind retry. Search-only scope; fetch/index deletion remain unavailable.
- Exact wire/key-lifecycle choices are documented for owner and independent security review, not represented as already reviewed or approved by the protocol document. Activation remains disabled until that review and a real trusted TLS adapter deployment are verified. The owner's broad permission authorizes development/tests, not an assertion of security verification.
- No second-party security verdict, desktop key-store/OS-path evidence or production mTLS transport is claimed. Q-19 remains open; missing mandatory review evidence prevents READY, not implementation.
