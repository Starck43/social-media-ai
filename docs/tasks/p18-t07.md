## Plan

1. PyInstaller builds per OS in CI; Linux AppImage/deb. Windows signing and macOS
   notarization are deferred (D6), so builds are unsigned and the install guide must
   state the SmartScreen / Gatekeeper steps a user has to take.
2. Signed update manifest; connector verifies signature before applying; rollback to
   previous version. The manifest signature protects the update channel and stays
   mandatory even while the binaries are unsigned.
3. Install/uninstall docs (`docs/LOCAL_CONNECTOR.md`), including data locations and complete removal.
