### Granular Sub-Steps
1. **`T05.1` — Deterministic `Decimal` Comparison Engine (`app/services/cases/calculator.py`):**
   - Normalize unit prices across currencies (`RUB`, `USD`, `EUR`), VAT modes (`with_vat`, `without_vat`), and pack sizes using `decimal.Decimal` (`ROUND_HALF_EVEN`).
   - Preserve `None` as explicit `"MISSING_PRICE"` (never interpolate, never use `float`, and never call an LLM for arithmetic).
2. **`T05.2` — Version-Bound Case Approval (`app/services/cases/approvals.py`):**
   - Bind product approval to `(actor_id, doc_version_hash, formula_version)`. Changing currency/VAT assumptions invalidates prior approval (`approval_state = "draft_invalidated"`).
3. **`T05.3` — FastAPI Domain Router (`app/web/cases.py`):**
   - Implement `router` for `/cases` rendering `web/cases.html` with `case_record` and `comparison_rows`.
