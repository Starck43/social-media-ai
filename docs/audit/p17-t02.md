Review of the accepted revision:

- Read-only by construction: the only HTTP method emitted is `GET`; no `POST`/`PUT`/`PATCH`/`DELETE` path exists in the package.
- Transport reuses the accepted P17-T01 seam: fresh resolution per attempt, connect to the pinned address with the original hostname for TLS (1.2+, certifi), redirects and non-identity `Content-Encoding` refused, 30 s timeout, 2 MiB body cap, path must start with `/` without control characters, refusal when `SSLKEYLOGFILE` is set.
- No OData injection: the plan is typed, `$filter` is rendered from `OneCFilterPredicate` values whose field must exist in `$metadata`, literals are formatted per `logical_type` (GUID, datetime, boolean, integer, decimal, string), `float` is refused, quotes are doubled, control characters and values over 512 characters are refused, and operators come from a fixed allowlist. `$select` and `$orderby` contain metadata-validated field names only.
- Authorization is checked per call, before cache lookup and budget spend: `_authorize(..., require_source_view=True)`, connection selected by `id + tenant_id + owner_user_id`, `is_active`/`verified`/`odata_standard` required, workspace host approved, secret opened from the vault, `$metadata` pinned by `metadata_sha256`.
- Allowlists fail closed: a missing or empty `allowed_entity_sets` yields `entity_not_allowed`, and the negative test proves the transport is never awaited on that path.
- Money: `json.loads(parse_float=Decimal)` plus `to_exact_decimal` and `quantize_money` (`ROUND_HALF_EVEN`), currency validated as ISO-4217 with a row-level override.
- Bounds: `MAX_ROWS_PER_REQUEST = 1000`, `MAX_SKIP_OFFSET = 100000`, cache TTL ≤ 300 s, cache ≤ 128 entries, history ≤ 200 entries.

## Findings carried forward

**F1 — XML DTD guard is positional (low, hardening).** `metadata.py` scans only the first 8192 characters for `<!DOCTYPE`/`<!ENTITY`, so a DTD placed after a long comment is accepted by the parser. Verified by probe: the early form is refused with `unsafe_xml_forbidden`, the displaced form parses into a valid catalog. Residual impact is contained: expat does not resolve external entities (`undefined entity`, no file read) and its built-in amplification limit refuses billion-laughs style expansion. The package has no importer yet, so the path is not reachable until P17-T03 wires it. Recommended fix before that wiring: refuse DTDs at the parser level (`defusedxml`, or an expat `StartDoctypeDeclHandler`) instead of scanning a byte prefix.

## Limitations

No live 1C base, no API/UI surface, no full test suite. Query history is in-process only (`deque(maxlen=200)`) because durable history belongs to P17-T03. Pagination tokens are unsigned and carry only `skip` inside `0..100000`, bound to the plan fingerprint but not to a connection; replaying one changes nothing beyond the offset. The connection row is locked `FOR SHARE` only while loading credentials, so a revocation does not wait for an in-flight read (bounded by the 30 s timeout), unlike the health path in P17-T01.
