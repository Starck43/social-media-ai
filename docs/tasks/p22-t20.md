# P22-T20 — Page older chat messages and saved task conversations

[Phase](../phases/p22-universal-tasks.md) · [Task conversations](../product/UNIVERSAL_TASKS.md#task-conversations) · [Agent runtime](../agent/AGENT.md#web-chat)

Reuse the authenticated conversation resolver in `app/web/chat.py` for main and task sessions. The web chat currently renders only the latest 40 messages.

- Return bounded pages with an exclusive message cursor anchored to the current conversation. On upward scroll, prepend older messages, preserve the viewport anchor and merge without duplicates. Do not allow a cursor or an in-flight response to switch session or workspace.
- Keep saved task conversations first in the initial picker window. Provide an explicit way to fetch older saved conversations when that window is full. Page the authorized bindings by a stable cursor and recheck workspace, actor and task access on every request.
- Accept with concurrent new messages, rapidly switched sessions, read-only history after closing work or attaching a scenario, and denied or mismatched cursors. Reading and paging must not invoke the model.
