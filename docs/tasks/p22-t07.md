# P22-T07 — Unified API, CLI and AI toolset

[Phase P22](../phases/p22-universal-tasks.md) · [Design](../product/UNIVERSAL_TASKS.md) · [Queue](../../ROADMAP.md#p22)

**Dependencies.** [P22-T03](p22-t03.md), [P22-T04](p22-t04.md), [P22-T05](p22-t05.md)

**Implementation ownership.** app/api/v1/endpoints/, new versioned task API, cli/commands/tasks.py, app/agent/toolset/, generated interface references.

## Deliverable

Expose canonical task references and shared DTOs for list/get, create/edit, preview, complete, confirmed delete, run-now, runs/results, available actions and decisions. Provide list filters and stable pagination, expected version, idempotency, supported action metadata and safe error codes. Keep v1 planner/task IDs and legacy commands/tools routable via compatibility adapters, without reinterpreting their payloads. Publish equivalent CLI help and constrained tool schemas.

## Acceptance

The same actor creates a plain note, adds a plan and manually runs a scheduled task against the same identity through all three surfaces. Preview has no effects. Rights, visibility, pending-decision rules and confirmation match the service; hidden fields cannot be injected. Old social result and planner requests still resolve correctly.
