## Scope and acceptance

Spawned from [P8-T33](p8-t33.md) on the owner's 2026-10-31 decision that every
deferred category keeps its own card. Scope: the **apps/games** search-result
category.

Add the category to the registry in
`app/services/collection/search_categories.py` and dispatch it through the
collection adapter only after an official public search method is confirmed to
exist — if none does, record the category `unsupported` with that evidence
instead — and its parameters, credential mode and app profile have verified
capability. Q-5 owns live
method/profile evidence; mocked contract work may proceed while it is open, with
no live availability claim or user-enabled category before that evidence.

Return category-specific typed results with the correct owner/account IDs,
stable provenance/links, bounded paging/fan-out, partial failure and explicit
unavailable-category details. An app or game result is not a Source unless the user
explicitly adds a supported target. Use only official VK API methods; no
browser scraping. Keep the five-surface read-only catalog parity established by
P8-T33 (web, API, CLI, admin, agent).

Accept with method-level parameter/scope evidence, mocked
success/permission/partial/error tests and recorded bounded concurrency/quota
behavior.
