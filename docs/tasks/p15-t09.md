## Goal

Register `comms.outbox` in the central access catalog with the owner-approved, migration-free metadata-permission presets.

## Approved catalog composition and remaining D14 gate

The existing D14 text names `VIEW`, `CREATE`, `APPROVE`, and `CONFIGURE`, but the current `ActionType` enum has no `APPROVE`. The owner approved the following migration-free catalog composition for metadata permissions:

| Role | Actions |
| --- | --- |
| Owner / admin | `VIEW`, `UPDATE`, `CONFIGURE` |
| Manager | `VIEW`, `UPDATE` |
| Analyst / viewer | `VIEW` |

This does **not** replace D14 `APPROVE` with `UPDATE`. `UPDATE` is metadata editing only and never grants approval or send authority. `APPROVE` remains unimplemented and unsupported; P15-T05 must retain a separate fail-closed approval gate before activation. No role receives `CREATE`.
