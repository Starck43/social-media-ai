# P21-T03 — Atomic LLM admission and quota reservation wiring

Registry: [ROADMAP](../../ROADMAP.md); parent: [P21](../phases/p21-ai-operations.md).

## Goal

Wire the reviewed admission/reservation foundation to the dispatch seam so capped
work cannot pass through a concurrent read-then-compare race. Preserve separate
workspace and personal payer contracts until an owner-approved convergence exists.

## Dependencies and owner gate

- Depends on P21-T02 and the existing `llm_dispatch_receipts`,
  `llm_budget_days`, `llm_budget_reservations`, and personal billing contracts.
- P2-T09 remains the later production verification gate; this card is local,
  mocked and isolated-schema implementation evidence only.
- Before changing charge semantics, enabling a cutover, or changing a payer
  contract, obtain the owner decision required for money-related changes.

## Steps

1. Select the authoritative admission path for each payer and document why the
   other path remains compatible or dormant.
2. Reserve payer/day budget and append the immutable receipt in one owned
   transaction before HTTP; fail closed on missing baseline, payer or schema.
3. Replace the effective daily-cap read-then-compare admission in the seam with
   the reservation result; do not sum journal/projection rows as a second ledger.
4. Cover fallback, retry, tool, digest, learning, analysis and prompt-suggest
   callers with distinct payer-bound attempts.
5. Add two-session PostgreSQL race tests and cleanup/inventory evidence.

## Acceptance

- At the cap, concurrent reservations admit no intentional overshoot.
- A denial produces no provider request and cannot select a paid fallback.
- Receipt and reservation are acknowledged only after commit; no lock spans HTTP.
- Separate tenant/personal payer isolation, idempotency and exact replay are
  demonstrated; legacy projections remain adapters.
- Flag-off and missing-foundation behavior is explicit and fail-closed.
- Isolated migration/schema checks, synthetic-record cleanup and exact test
  commands are recorded. No public migration or production cutover is performed.

## Rollback and boundaries

Retain the existing unwired foundation and disable the seam feature flag on
failure. Do not delete historical evidence, rewrite tariffs or merge payer
contracts in this card.
