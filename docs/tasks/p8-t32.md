### Findings

1. **Blocking, fixed (`9534f9a`).** `row_link` called
   `request.url_for(f"admin:{action}", ...)` unguarded. On any console whose
   target view has no route in the active router — the narrowed admin test
   harness, a view outside this router, a narrowed role console — Starlette
   raises `NoMatchFound` and the *whole* host page fails, not just that cell.
   Measured: `tests/admin/test_p8_t31_inline_pagination.py` alone → **36 failed**
   with `NoMatchFound: No route exists for name "admin:details"`. A missing
   navigation must degrade to plain text, which is also what the acceptance
   says ("otherwise plain text"). Now caught around `url_for` and returns
   `None`, which the template already renders as plain text.
2. **Contract pin updated (`9534f9a`).** `test_limit_after_scope_and_no_unfiltered_total_or_write_controls`
   asserts the exact section key set; P8-T32 adds `row_links` and
   `link_columns`. The pin is extended with both keys and a comment, not
   loosened — the regression guard against new unfiltered queries per section
   still holds.
3. **Not a finding, checked:** link decisions receive only the scoped scalar
   shell (`view.model(**row)`), never a relationship; `check_can_edit` /
   `check_can_view_details` reuse SQLAdmin's own hooks; destination routes
   recheck authority; no new write endpoint, query or migration; the personal/
   workspace projection and the `collected_items` deny-list are untouched.
