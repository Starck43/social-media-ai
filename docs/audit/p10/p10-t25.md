## Finding found and corrected in audit

The test shipped with `zip(..., strict=True)`, so the documented
`python -m unittest discover` command failed on CPython 3.9 before any assertion
ran. The keyword was removed and the equal-length invariant is now asserted
explicitly, so coverage is preserved without narrowing the interpreter range.
Correction commit `fe04ab85`; the delivered command is green on all three
interpreters above.
