## Goal and dependencies

Present tasks as one universal tool while storage stays separate ([R-03](../BUSINESS_MODULES.md#review-findings-corrections-to-the-tz)). Depends on [P16-T01](p16-t01.md) (planner) and the existing agent tasks; calendar view after [P16-T03](p16-t03.md). Follows D24/D25/D26 ([Q-21](../audit/q-21-source-authority.md)).

## Scope

- «Задачи» hub with tabs «Мои дела» (planner), «Поручения агенту» (`/app/tasks`) and «Календарь» (read-time view of planner due items, calendar events and scheduled agent runs); no merged table.
- «Поручить агенту» from a planner task creates a linked agent task by reference; an agent result may annotate or complete the planner task only after user confirmation.
- Quick creation from chat, inbox message, document and «Сегодня» through the owning services; labels per owner decision O-1.

## Acceptance and checks

- Tests: permission filtering per kind, link integrity when either side is deleted or inaccessible, calendar unavailable state, timezone/DST in the view, no duplicate items across tabs, accessibility.
