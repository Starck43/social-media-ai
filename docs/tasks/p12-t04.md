## Scope and acceptance

Deliver the `/app/communications` and `/app/followups` views for managing verified contacts, channel threads, approved outbound replies, and evidence-backed reminders:
- Flag ambiguous contact identities or channel routes for explicit operator review before drafting or sending.
- Implement the outbound lifecycle UI (`draft → validated → approved/scheduled → claimed → confirmed/failed/unknown`) where approval binds actor, tenant, exact recipient, payload/document version, and TTL, with cancellation/kill-switch controls and no blind resends on ambiguous timeouts.
- Present follow-up reminders (unanswered requests, commitments, birthdays, expiries) with uncertain-date confirmation, quiet hours, snoozes, duplicate suppression, and retention-preview-gated archive/delete actions.

Accept with actor-bound confirmation/TTL tests, per-target idempotency/timeout state checks, and quiet-hours suppression tests.
