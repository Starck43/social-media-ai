# P20-T12 — Web research source: search and public page fetch

Registry: [ROADMAP](../../ROADMAP.md#p20); status, owner and dialogue live there. Parent: [P20](../phases/p20-proactive-assistant.md). Design: [WORKSPACE_UX](../WORKSPACE_UX.md). Request: https://app.notion.com/chat?t=40fa7457748980d094a100a930619250

## Goal and dependencies

Cover everyday research («найди в интернете», «разбери сайт») with an official search API and plain HTTP fetch of public pages before any browser automation ([COLLECTION](../COLLECTION.md#collection-layers)). Uses the existing task plans, evidence and egress seam ([P14-T09](../audit/p14-t09.md)); a prerequisite for deciding whether [P20-T05](p20-t05.md) is needed.

## Scope

- One search provider chosen by the owner (O-5) behind a typed connector capability with per-account budget, rate limits and redacted errors.
- Public page fetch: destination validation (no private/metadata addresses, redirect and rebinding checks), size/time/content-type limits, robots and terms respected, page text treated as untrusted data, evidence snapshot with URL, time and hash under current retention.
- Agent task step and chat tool for search → fetch → evidence-linked summary; no login, form submission or CAPTCHA handling.

## Acceptance and checks

- Mocked provider and local fixtures: SSRF/redirect/rebinding refusal, oversize and slow pages, prompt injection in pages, budget exhaustion, cross-tenant evidence isolation, citation coverage. No live calls without owner authorization.

## Open doubts

O-5 provider and spend. Default: design and mocks only until approved.
