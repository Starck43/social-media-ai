### Granular Sub-Steps
1. **`T03.1` — Permission & ACL Retrieval Service (`app/services/knowledge/retrieval.py`):**
   - Filter indexed snippets from mounted `Source(DRIVE_FOLDER)`, email, and local gateway folders by `acl_scope` and `data_boundary` (`local_only | company | cloud`) **before** returning results or assembling LLM prompt context.
2. **`T03.2` — Versioned Document Service (`app/services/knowledge/documents.py`):**
   - Track document revisions by `content_hash` (`sha256:...`). Any edit to `body_text` creates a new revision and resets `status = "draft_invalidated"`, `approved_by = None` (`edits invalidate approval`).
3. **`T03.3` — FastAPI Domain Routers (`app/web/knowledge.py`, `app/web/documents.py`):**
   - Implement `router` for `/knowledge` and `/documents` rendering `web/knowledge.html` and `web/documents.html` with the exact template context below.
