## Goal

Persist drafts and scheduled messages with exact approval binding and per-target outcomes.

## Baseline

- P12-T04 outbox state machine and approval binding as pure functions over dicts; follow-up quiet hours.

## Plan

1. Models `outbox_messages` (tenant, author, contact, content encrypted, content hash, state, scheduled at, command ref) and `outbox_targets` (channel, connection, recipient identity, idempotency key, state, attempts, provider message ID, error code).
2. Port P12-T04 transitions to the persistent model; keep the pure functions as the single transition table.
3. Runtime job `comms.outbox.dispatch`: claims due approved targets with `FOR UPDATE SKIP LOCKED`, rechecks approval/consent/connection, calls the channel sender ([P15-T06](p15-t06.md)), records outcome; quiet hours defer.
4. Multi-channel: one message → several targets, each independently tracked; cancel before claim.
5. API `POST /api/v1/communication/outbox/draft|schedule`, `GET …/outbox/scheduled`, `DELETE …/outbox/scheduled/{id}`.
