## Goal

Connect one or more 1C:Enterprise 8.3+ bases per workspace safely.

## Baseline

- Catalog descriptor `ONEC` (`odata_credentials` login/password); `PlatformType.ONEC`; no adapter.

## Plan

1. Connection config: name, base URL (HTTPS, host allowlisted per workspace by an admin; no private/loopback addresses unless via the D5 tunnel), interface `odata_standard` (`/odata/standard.odata/`) or `http_service` (published service base path), auth `basic` (OAuth if the base supports it).
2. Credentials as connection secrets; recommend a dedicated read-only 1C user; write user is a separate connection method used only by [P17-T04](p17-t04.md).
3. Client with 30 s timeout, response size limits, rate budget 10 req/min, fixed error codes.
4. Health check: `$metadata` fetch (OData) or service ping; store discovered metadata version hash.
5. API `/api/v1/integrations/1c/connect`, `/connections`, `DELETE …/{id}`, `POST …/{id}/health-check`; Settings card.
