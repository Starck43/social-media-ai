## Goal

Combine identities of one person across channels with human control and reversible history.

## Baseline

- Contact core merge journal ([CONTACTS](../CONTACTS.md); [acceptance](../audit/p13-t07.md)).

## Plan

1. Suggestion engine: exact blind-index matches (email/phone) = strong; same display name + shared thread = weak; scores and reasons stored, never auto-merged without confirmation (owner may enable auto-merge for verified exact matches later).
2. Merge operation: choose survivor, move identities/messages/stats, record journal entry with full before-state; conflicts (different names/birthdays) resolved by explicit field choice.
3. Unmerge: restore from journal, re-point moved identities and messages.
4. API `POST /api/v1/communication/contacts/merge|unmerge`, suggestions list; `/app/contacts/merge` UI.
5. Audit `comms.contact.merge/unmerge`.
