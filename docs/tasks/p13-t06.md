## Goal

Make the TZ requirement "coverage ≥ 80%" enforceable per new package without running the whole legacy suite, and give adapters shared HTTP mocks and tenant fixtures.

## Baseline

- Coverage is opt-in (`pyproject.toml`); offline CI profile in `.ci/` and `scripts/ci/`.
- Full suites require an explicit owner request.

## Plan

1. Add `scripts/ci/package_coverage.py <package…> --min 80 [--tests …]`: runs focused pytest with `--cov=<package>` and `--cov-fail-under`, prints a short table, exits non-zero below threshold.
2. Register new business packages in a small manifest (`scripts/ci/coverage_packages.toml`) so CI can run the gate for touched packages only.
3. Add `tests/shared/provider_http.py`: `httpx.MockTransport`-based fakes with recorded fixtures for Bitrix24, Google Calendar, CalDAV, 1C OData, IMAP/SMTP doubles; network access is blocked in these tests.
4. Add `tests/shared/business_tenancy.py`: two-workspace/two-actor fixtures and an assertion helper for cross-tenant not-found.
5. Document usage in `tests/shared/README.md`.
