## Acceptance

- **Aggregate cannot import adapters from its application core — met.**
  `package_boundaries` passes with 11 modules in the graph and none of
  `app.models`, `app.agent`, `app.channels`, `app.api`, `app.web`; importing
  `task_preparation` loads only the `app.core`/`app.services` chain and no
  `sqlalchemy`.
- **Compatibility preserved — met.** `getattr(task_creation, name) is
  getattr(task_preparation, name)` holds for all five moved names, so callers
  compare and catch the same objects. `except task_creation.TaskPlanCreateConflict`
  catches the exception raised by `task_preparation.prepare_task_plan_create`.
  `persist_task_create` and `create_task_with_sources` are unchanged.
- **Import-time smoke — met as far as hosted evidence goes.** The hosted package
  profiles (`core`, `dev`, `legacy-celery`, `qr`, `telegram`) succeeded. The
  auditor did not rebuild the wheel locally, so that part rests on hosted runs.
- **No blanket `# noqa` — met.** Production code adds none. The only `# noqa` in
  the diff belongs to a negative fixture written to a temporary directory that
  asserts the scanner is not silenced by `# noqa`.

Mutation probes confirmed the contract rejects real regressions: eager, relative,
`TYPE_CHECKING`-only and `# noqa`-suffixed imports of `app.api` from
`task_preparation` all fail the scanner, as do an `importlib.import_module` call
inside a function, an unreviewed `sqlalchemy`/`pydantic` import, a back-edge from
`app.services.task_plans`, and a cycle from `core/settings_views`.

## Residual debt

- The re-export layer is temporary. Removing it requires migrating the 12
  production import sites and three test modules in one change.
- `TaskPlanCreate.__module__` is now `app.services.task_preparation`, so the repr
  and pickle path of the old name changed. No consumer relies on either.
- `task_preparation` still reaches `app.core.config` transitively through
  `app.services.task_plans`; the documented "pure" core is pure of persistence
  and adapters, not of configuration.
- One tooling test mutates a temporary copy of `app/core/settings_views.py`
  without seeding the original file first; the assertion holds only because the
  created file is new.
