## Limitations recorded, not defects

- Browser data on the clone carries no pending approvals, so the badge was proven by template render and by the unit test
  rather than visually.
- With restricted permissions a group can shrink to a single item (analysis-only actor sees «Агент › Аналитика»). The rule
  «no single-item group» governs the complete structure; permission filtering cannot invent a second entry, and hiding the
  heading instead would make the entry read as a pinned one.
- `tests/jobs/test_web_digests_jobs.py` (heading assertion renamed to «Рассылки») and the browser stands
  `tests/browser/p20_t13_shell_layout.cjs`, `p20_t16_live_smoke.cjs` need the DB test schema and their own storage state,
  which `test_schema` still lacks; they were not executed.
- Pages of the retired surfaces still carry their old headings; the redirects belong to P22-T12.
