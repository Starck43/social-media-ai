## Finding

The Home strip combined all three data reads (CollectedItem, AIAnalytics,
Job) whenever the caller could view analytics *or* tasks, and the `/app/jobs`
link was unconditional. A denied component still issued its data query and
showed its link; independently authorized components were unsupported.

## Solution

`dashboard._pipeline` reads each component only under its own active-workspace
view right and no query runs without a selected workspace (superusers keep the
`scope_all` placeholder, no global read). `_offers` adds `collected_items`
(`collection.collected_item.view`) and `jobs` (`scheduling.job.view`); the
template independently hides each denied cell, the job activity/empty state
and the queue link. Catalog, middleware, `WebPerms` and nav are untouched, so
no new rights are implied and the `/app/jobs` section gate and the queue link
stay consistent. Job `limit(3)`, count definitions and labels are unchanged
(P10-T09 territory; the new suite pins `limit == 3`).
