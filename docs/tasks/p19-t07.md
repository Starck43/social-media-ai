`documents.py` clear 80%; the meaningful work is the untested paths, not the percentage.

## Plan

1. Read the uncovered ranges in `documents.py` and group them by feature: list/filter dto
   construction (76-81, 117-156), create/update validation (164-188), revision and restore
   branches (495-502, 565-593), export/attachment wiring (638-662, 700-725).
2. Add DB-backed tests in `tests/knowledge/` for the groups that carry behaviour (tenant scoping,
   revision pointer, tag/contact/case-evidence links), not for line coverage of trivial branches.
3. Keep the tests off the network and off paid providers; mock external writes as the rest of the
   suite does.
4. If a range turns out to be dead code or unreachable duplication, delete it instead of covering
   it, and say so in the card.
