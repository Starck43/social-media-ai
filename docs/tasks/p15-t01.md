## Goal

Read new messages from selected mailbox folders into unified message metadata.

## Baseline

- Mail.ru/Yandex mail connections with encrypted app password and IMAP login check only (P12-T08); fixed provider presets, pinned TLS network policy.

## Plan

1. Folder selection per connection (default INBOX + Sent), stored as non-secret config.
2. Sync job `comms.email.sync`: per folder track `UIDVALIDITY` + last UID; fetch headers (`ENVELOPE`, `Message-ID`, `In-Reply-To`, `References`) in bounded batches; `BODY.PEEK` only so messages are never marked read.
3. Write `unified_messages` metadata via [P15-T02](p15-t02.md) ingestion API; body/attachments to the optional content cache per D3.
4. UIDVALIDITY change → full re-scan with dedupe by `Message-ID` hash.
5. Map addresses to contact identities (email kind).
