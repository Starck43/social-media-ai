## What was wrong

The secret gate compared a fresh scan with a frozen inventory that had not moved since P11-T03, so
`dev` carried **94 candidates outside `.ci/secret-baseline.json`** across 53 touched-by-nobody
files. That is not a leak by itself; it is worse than one, because a permanently red gate teaches
reviewers to ignore the only signal that would catch a leak. Two of the 94 sat in application code
(`app/api/v1/endpoints/onec.py`, `app/services/calendar/service.py`), which is exactly the class a
blanket "docs noise" excuse would have missed.
