## Goal

Implement senders as separately enabled capabilities with honest outcomes.

## Baseline

- `send_enabled=false` for mail presets; P9 Telegram channel-post capability; MAX channel transport.

## Plan

1. SMTP sender for Mail.ru/Yandex presets (implicit TLS 465, app password), `Message-ID` generation, `In-Reply-To` for replies; capability `comms.email.send.v1`.
2. Telegram bot private message to users who started the bot (`comms.telegram.bot_send.v1`); no MTProto sending.
3. MAX bot message capability (`comms.max.bot_send.v1`) following MAX API rules.
4. Each capability off by default with kill switch and exact workspace bindings, mirroring ACTION_ACTIVATION; timeouts → `unknown`.
5. Update CHANNELS and CONNECTOR_CONFIGURATION docs.
