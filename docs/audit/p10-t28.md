## Scope accepted

For the three P10-T26 domains: canonical domain leaves under
`app/models/{notifications,actions}/`, root modules reduced to pure explicit
re-exports, and every manager importing its model from the canonical leaf
instead of the root compatibility module. The remaining root modules are
mechanical follow-up work (one domain at a time) per the original card.

## Limitations (registered, not blocking)

The full `tests/models/` run on the integrated dev exposes **six** failing
legacy-symbol assertions in `tests/models/test_analysis_model_layout.py` and
`tests/models/test_scheduling_model_layout.py` (parameters
`agent_scenario./LLMStrategyType`, `agent_scenario./TenantScopedMixin`,
`ai_analytics./Decimal`, `ai_analytics./PeriodType`, `job./TenantScopedMixin`,
`BotAction` mapper/manager path). The same files pass 80/80 on pre-#246 dev
(`1ddb5455`), so the gap was introduced by the P10-T28 shim rewrite: the
explicit re-export lists omit helper symbols the pinned layout tests require.
App code only imports model classes from root paths (grep-verified), so there
is no runtime break. Fix belongs to [P10-T31](../tasks/p10-t31.md).
