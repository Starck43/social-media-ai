## Non-blocking notes

- `search.py:155` — `KnowledgeDocument.tags.contains([tag])` compares exact tag membership, which
  is the documented behaviour, but a user searching `q` also matches the JSON text of the tag
  array, so `%` and punctuation inside tags can produce surprising hits. Cosmetic.
- `search.py:74` — `can_view_contacts` is computed on every search even when `contact_id` is
  absent; negligible cost, worth noting for a later hot-path pass.
- `tests/knowledge/test_p19_t06_search_db.py` reuses the P19-T01 fixture layer; if that layer
  changes, this file follows it.
