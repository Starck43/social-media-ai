## Goal

Find documents by metadata. Content search is not built: D3 keeps document content out of any full-text index, and reopening it needs a new measured owner decision.

## Baseline

- Knowledge retrieval with ACL/boundary filtering (P12-T03).

## Plan

1. Metadata search over title, type, status, tags, contact, case, author and dates of the current revision; no `tsvector`, `pg_trgm` or content index (D3). Add a plain metadata index only if a measured query plan needs it.
2. ACL/boundary filtering before ranking (existing retrieval rules).
3. API `GET /api/v1/documents?q=…`.
