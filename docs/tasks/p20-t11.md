# P20-T11 — Team work through connected task systems

Registry: [ROADMAP](../../ROADMAP.md#p20); status, owner and dialogue live there. Parent: [P20](../phases/p20-proactive-assistant.md). Design: [WORKSPACE_UX](../WORKSPACE_UX.md). Request: https://app.notion.com/chat?t=40fa7457748980d094a100a930619250

## Goal and dependencies

Let teams keep collaborating in services they already use instead of a second tracker here. Depends on the shared source-object registry introduced by [P16-T04](p16-t04.md) and on the [P13-T04 command ledger](../audit/p13-t04-p14-t04-business-crm.md) for writes; follows D24/D25/D26 ([Q-21](../audit/q-21-source-authority.md)).

## Scope

- One pilot task system chosen by the owner (O-4), connected as a task source: read assigned/watched items by reference with link, status and due date as last learned facts; unavailable source stays visible.
- Show these items in «Задачи» and «Сегодня» as read-time entries; overlap with planner items is a suggestion, never an auto-merge.
- Writes (comment, status, assignee) are separate capabilities through the command ledger with preview and approval; read and write consent are per connection.

## Acceptance and checks

- Tests with mocked provider: paging/watermarks, rate limits, revoked token, cross-tenant isolation, conflicting edits (If-Match or provider equivalent), unknown write outcome, no mirrored status table.

## Open doubts

O-4 pilot selection (for example Bitrix24 tasks, already a connected CRM). Default: none until chosen; read-only first.
