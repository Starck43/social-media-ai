entries survive, no test selection, description or contract was removed, and `json.tool` parses the
result. Without this fix the row could not be integrated, so it is a deviation, not an independent
confirmation of the executor's revision.

- `GENERATIONS` now also accepts the intermediate revisions `0154`, `0155` and `0156` in addition to

  `telegram_login_attempts`, `telegram_login_request_keys`, then `llm_providers.credential_version`),
