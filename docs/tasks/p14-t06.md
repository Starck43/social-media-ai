## Goal

Send one personalized message to a selected set of 100+ contacts safely.

## Baseline

- Product boundary: no bulk invitations without supported API/opt-in (PRODUCT_PLAN).

## Plan

1. Template rendering with a strict variable allowlist (`{name}`, `{company}`…); preview of N rendered samples and the frozen recipient list.
2. Eligibility filter: consent for purpose, not unsubscribed, reachable channel; excluded recipients shown with reasons.
3. One batch approval (`crm.batch.send.v1`, `per_batch`) over the frozen list; per-target outbox items with idempotency keys; throttled dispatch per channel budget.
4. Retry only definite transient failures per target; `unknown` outcomes reconciled, never resent blindly.
5. Unsubscribe: email link with signed token, bot command; withdrawal recorded in `contact_consents`.
6. API `POST /api/v1/integrations/bitrix/messaging/batch`, `GET …/messaging/status/{batch_id}` with per-target status.
