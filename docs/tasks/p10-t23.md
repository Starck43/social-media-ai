## Audit findings and solution

- The legacy retry-cache module is self-contained, with no repository consumer.
  Its prompt-only process-global cache is not an appropriate future tenant/model
  isolation contract. Remove the unused module, not the active LLM retry code.
- The JSON Unicode-decoding wrapper has no repository consumer. Remove it rather
  than maintain a second JSON transformation path. No caller migration required.
- Slug transliteration built a Python list and filtered translated fragments.
  Replace it with one module-level `str.maketrans` table and compiled ASCII filter.
  Keep the same mapping, lowercase order, ASCII-only output and public signature.
  No application-throughput or quantified speedup claim is made.
- Leave the differing stemming/date/enum helpers and AI callers unchanged: their
  semantic contracts or active lanes do not authorize broad deduplication.
