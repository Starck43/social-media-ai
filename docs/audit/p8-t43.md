## Accepted result

/ `unsupported_attachment` state), `source_id` and `tenant_id` survive collection
(VK, Telegram L1/L2) → staging/replay → analyzer context and `summary_data`
evidence → agent `task_result` → `/app/analytics/{id}` rendering, with daily
`AIAnalytics` merges retaining evidence. No schema/migration change: existing
`collected_items.permalink`, `collected_items.attachments` and
`ai_analytics.summary_data` cover it. Media is reference-only.

   oversized/whitespace URLs — conservative, no DNS or fetch performed. Safe
   expectations documented in tests.
