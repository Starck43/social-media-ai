# P20-T17 — Work surfaces usability and visual standard

Registry: [ROADMAP](../../ROADMAP.md); parent: [P20](../phases/p20-proactive-assistant.md); related: [P20-T16](../audit/p20/p20-t16.md); owner request: local owner chat, 2026-11-20.

## Goal

Review and simplify the four primary Work surfaces — Today (`/app/`), chat (`/app/chat`), communications (`/app/communications`), and tasks (`/app/task-hub` / planner) — against `backups/social-media-ai-макеты-разделы.pdf`. Establish one readable visual standard for filters, controls, icon actions, empty states, and page-specific navigation while preserving the shared sidebar, existing backend/security contracts, two themes, responsive behavior, and real action semantics.

The owner explicitly permits synthetic test records in public schemas for personal testing. They must be isolated, labelled, and removed or verified after focused checks according to the database rules.

## Stages

1. Audit the four screens against the owner PDF and the existing `/app/analytics` filter/control language. Extract reusable UI rules, apply the shared filter/button treatment to the four Work templates, and simplify the visible page hierarchy without changing action behavior.
2. Today page. Remove the ambiguous top-level «Подготовить дело» action, expose useful item actions directly with accessible SVG icons, and reorganize the dashboard blocks for clearer daily work.
3. Chat. Improve the workspace panel value, make one modern toggle the sole open/close control with a smooth accessible transition, and refine the composer and quick commands.
4. Communications. Remove the redundant record-scope block, restyle and simplify filter application, hide irrelevant content in empty states, and lead users to connect messages through the existing connector flow.
5. Tasks. Align the planner with the PDF, remove redundant view/action controls and memorial-date planning UI, move «Новая задача» into the page navbar, and design a single modal entry point for personal, team, agent, collection, and analytics tasks without breaking existing routes.
