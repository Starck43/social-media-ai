### Granular Sub-Steps
1. **`T04.1` — Outbox State Machine (`app/services/communications/outbox.py`):**
   - Implement `draft -> validated -> approved -> sent | uncertain_delivery | failed` with single-use approval bound to `(actor_id, content_hash, ttl_expires_at)` and kill-switch cancellation.
   - Provider timeout transitions message to `uncertain_delivery` without blind automatic retry.
2. **`T04.2` — Route Verification & Quiet Hours Follow-ups (`app/services/communications/followups.py`):**
   - Block transition to `approved` when `route_verified is False`; enforce tenant quiet hours (`21:00–08:00`) on reminder scheduling.
3. **`T04.3` — FastAPI Domain Routers (`app/web/communications.py`, `app/web/followups.py`):**
   - Implement `router` for `/communications` and `/followups` rendering `web/communications.html` and `web/followups.html`.
