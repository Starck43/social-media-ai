## Microplan

- [x] 1. Register the task and publish the claim before solution edits.
- [x] 2. Add a read-only, bounded task picker and selected-task snapshot endpoint.
  Require current chat/task access and active workspace; query explicit tenant scope;
  reuse canonical permission-filtered plan/result readers; never expose raw payloads,
  errors, credentials, foreign tasks or restricted source/scenario data.
- [x] 3. Add a persistent right panel with quick actions and task selection.
  Parameterized actions prepare editable drafts and never silently send or overwrite
  existing text. Keep existing quick replies and confirmation handling. A selected
  task has an explicit removable label; every submitted task-scoped request carries
  its concrete ID to the shared runtime, without granting additional permissions.
- [x] 4. Show the selected task's canonical plan and honest latest-run summary in
  the panel, plus existing detail/result links and explicit refresh. Empty, denied,
  loading, unavailable and refresh-error states must be visible. Do not infer state
  from assistant prose or invent progress percentages. Keep task execution on its
  established preview/confirmation path, rather than a duplicate launch endpoint.
- [x] 5. Make the panel collapsible on desktop and mobile; preserve chat width,
  focus, keyboard use, reduced motion and existing shell navigation. Remove the
  unsupported upload button; show accessible focus indicators.
- [ ] 6. Delegate necessary tests to children: read authorization/tenant filtering,
  draft preservation, explicit context, failure/race handling and real-template
  desktop/mobile interaction. Coordinator implements production code only.
- [ ] 7. Run affected tests, then main shared chat/interface/browser/offline checks
  through the configured runner. Record exact revisions, commands, actual results
  and limitations. No full suite, production runtime, live providers or DB tests
  unless needed by actual imports/resources and guarded under project policy.
- [ ] 8. Review the diff, commit scoped changes and record a portable handoff with
  source revision and remaining acceptance/integration steps. Clean owned scratch
  and completed child artifacts after preserving evidence; preserve foreign work.
