## Baseline

## Plan

1. `file.fetch` only after a user confirmation in the web UI showing name, size and destination; transfer streamed, hash verified, stored in P12-T12 private storage with retention.
2. Version tracking: content hash per indexed file; cloud evidence shows when the local file changed after fetch.
3. `index.delete` and ‘Remove all data’ in the connector; server-side cached snippets for the device purged on revoke.
