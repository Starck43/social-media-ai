# P9-T08 — approval-bound action ledger (BotAction → outbound action)

**Verdict:** ACCEPT · 2026-10-27 · independent acceptance by OpenCode —
implemented inside PR #246, accepted at head `898f904b`, integrated into dev
as merge `4e74318c` with the 0113–0116 migration chain.

## Scope accepted

`bot_actions` becomes an approval-bound ledger: PENDING → APPROVED|REJECTED,
APPROVED → EXECUTED|FAILED transitions enforced, approvals sealed with
`approved_by`/payload binding and `approval_expires_at`, durable claim/outcome
handling in the dispatch path, admin surface read-only
(`NotificationAdmin`/`BotActionAdmin`), and transition history preserved after
membership/account deletion (migration 0116).
