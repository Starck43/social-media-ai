## Delivered contract and review

Extends the accepted [P11-T04 CREATE seam](p11-t04.md): configuration and explicit
source links commit atomically. `app/services/task_creation.py` provides an owning
session/transaction helper and an explicit-session primitive that rejects a
missing active transaction. It resolves the tenant through the existing manager,
rejects a mismatched requested tenant, acquires the existing workspace admission
gate before insertion, and passes one session to participating manager writes.
It adds no permission grant or ambient session mechanism.

Web and agent CREATE use the owning helper. REST CREATE and CLI retain explicit
caller transactions where their existing link-update permission scope must stay
narrower than creation. Legacy CLI no longer commits the task before links;
legacy REST `/tasks/run` also commits its inactive temporary row and links as one
unit before enqueue/dispatch. Source-link errors propagate out of the UoW and
roll back the whole unit. Existing scenario validation, task-owned-source checks,
tenant guards and the tenant/name unique constraint remain authoritative.

Payer consent and activation are separate recoverable steps after create commit:
a failed billing setup leaves an inactive draft. Queue/admission failure for a
legacy one-off leaves an inactive temporary task with its explicit links and no
next-run time; it can be retried or deleted. This is the specified recovery state,
not atomic creation-plus-enqueue or an exactly-once retry receipt. Provider/network
execution is outside the create transaction. No schema/migration change.

SQLAdmin retains its framework-owned transaction: the installed
`sqladmin._queries.Query._insert_async` applies attributes/relationships and adds
the row before its single commit. Its validation hook is not replaced by a
separately committed manager call. This is source-inspected existing behavior;
new DB failure-injection proof concerns the selected manager-based CREATE paths.
Update/delete operations, broader P8-T39 journeys and transaction redesign of
provider execution are outside this slice.

`app/agent/toolset/tasks.py`, `app/api/v1/endpoints/tasks.py`, `app/web/tasks.py`,
