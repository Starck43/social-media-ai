## Scope and acceptance

Found during P10-T26 (source `a8aee6a3`) in `app/api/v1/endpoints/notifications.py`:

- `GET .../stats` builds counters but returns nothing → `response_model` failure.
- `notification_type` filter passes `NotificationType.value` (a tuple) instead of
  the enum member.
- Router prefix `/notifications` plus route `/notifications` yields
  `/api/v1/notifications/notifications/...`; `docs/API.md` documents
  `/api/v1/notifications`. Decide one path (keep a compatibility alias if clients exist).
- Read-all and cleanup loop `update_by_id`/`delete` per row; use
  `NotificationManager.mark_all_as_read` / bulk queryset delete.
- `POST` creates free-text workspace notifications; confirm whether this public
  write is needed or should be operator-only.

Accept: focused ASGI tests for list filter, stats, read-all, cleanup and route
path; tenant isolation preserved; docs/API.md matches. Depends: P10-T26.
Owns: `app/api/v1/endpoints/notifications.py`, `app/schemas/notification.py`,
`docs/API.md#notifications`, new `tests/notifications/test_p10_t27_*.py`.
