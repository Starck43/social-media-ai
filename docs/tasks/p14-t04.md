## Goal

Show upcoming birthdays/anniversaries 7/3/1 days ahead and prepare personalized greeting drafts without sending anything.

## Baseline

- LLM pipeline with payer/budget controls (P2/P5); structured output contracts.
- Follow-up quiet hours (P12-T04).

## Plan

1. `crm_greeting_events` view/service: compute upcoming events in the workspace timezone (Feb 29 → Feb 28 in non-leap years); remind at 7/3/1 days via notifications.
2. Model `greeting_history`: tenant, contact, event type, event date, year, channel, draft text (encrypted), status `draft|approved|sent|failed|skipped`, command ref; unique `(tenant_id, contact_id, event_type, year)` to avoid repeats.
3. Draft generation through the existing LLM pipeline with a typed output schema, contact context limited to allowlisted fields, payer/budget checks; mark generated text as AI draft.
4. API `GET /api/v1/integrations/bitrix/greetings/upcoming`, `POST …/greetings/draft`; UI list with edit/approve-for-send placeholder disabled until [P14-T05](p14-t05.md).
