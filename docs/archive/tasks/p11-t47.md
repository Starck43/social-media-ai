## Problem

`scripts/check_markdown_links.py` reports 16 broken local targets on `dev` `7359da9b`, all of the
same shape: a document was moved or archived, but its relative links kept the depth of the old
location. Two sub-classes:

1. **Archived cards keep working-directory-relative prefixes.** After the move from `docs/tasks/`
   to `docs/archive/tasks/` every `../phases/…`, `../product/…`, `../audit/…` and `../../ROADMAP.md`
   is one level short: from `docs/archive/tasks/` the repository root is `../../../` and `docs/` is
   `../../`.
2. **Audit records point at a moved card.** `docs/audit/p11/p11-t38.md` and
   `docs/audit/p11/p11-t39.md` link `../../archive/tasks/p11-t4[124].md` for cards that are still
   open in `docs/tasks/`, and `docs/audit/p21/p21-t13.md` uses the `docs/audit/`-rooted prefixes from
   its old location.

Both classes are anchor-free navigation links: a reader of an archived card or of an accepted audit
lands on a dead path.

## Reproduction

```bash
.venv/bin/python scripts/check_markdown_links.py
```

`dev` `7359da9b` prints 16 `missing target` lines:

- `docs/archive/tasks/p18-t06.md` ×5
- `docs/archive/tasks/p8-t50.md` ×3
- `docs/audit/p11/p11-t39.md` ×4
- `docs/audit/p11/p11-t38.md` ×1
- `docs/audit/p21/p21-t13.md` ×3

## Expected change

1. Repoint every one of the 16 targets to the file that actually exists; do not move or delete any
   document, and do not weaken the checker.
2. Add an offline gate so the class fails closed: `tests/tooling/test_p11_t47_markdown_links.py`
   runs the checker and asserts it reports no missing target, registered in `.ci/offline-tests.json`.
   Without the gate the next archive repeats the defect silently — it already happened three times.
3. Record in the task card which links were repaired and how the gate behaves on an intentional
   break, so the acceptance can re-verify.

## Boundaries

- Documentation links plus one new tooling test; no product code, migration, guard DDL or CI contract
  change beyond adding the test file to the offline manifest.
- Foreign accepted documents are edited only in their link targets — nothing else in
  `docs/archive/tasks/p18-t06.md`, `docs/archive/tasks/p8-t50.md`, `docs/audit/p11/p11-t38.md`,
  `docs/audit/p11/p11-t39.md` and `docs/audit/p21/p21-t13.md` changes.
- Rollback: revert this task's commits; the documents keep their current wrong depth, which is the
  pre-task state and breaks nothing at run time.
