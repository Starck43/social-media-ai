# P18-T04 — Text extraction and OCR with resource limits

**Verdict: ACCEPTED — 2026-11-08.** Accepted source `e74b8e81`, PR
[#442](https://github.com/Starck43/social-media-ai/pull/442), merged into `dev` as
merge commit `11767207`.

## Delivered

- `local_connector/extract/` — bounded extractors for PDF (page anchors), DOCX
  (paragraph anchors), XLSX (sheet/cell anchors), plain text and Markdown with
  encoding detection, raster images, and Tesseract OCR (`rus+eng`) for scans.
- `DocumentLimits` — one shared budget: file size, character cap, wall-clock per
  file, ZIP declared-size guard checked before any OOXML parse, per-format
  page/sheet/row/paragraph caps, and a per-invocation OCR budget (CPU rlimit,
  wall timeout, memory, bounded language names).
- OCR runs in a bounded subprocess with a private 0600 scratch file and a fixed
  command shape; on wall timeout the whole process group is SIGKILLed, so no
  group member outlives the call. Failures become note codes from a fixed set,
  never exceptions.
- **Format backends are resolved lazily.** An absent `pypdf`, `python-docx`,
  `openpyxl` or `Pillow` degrades that format to a note code instead of breaking
  package import; the connector keeps indexing everything else.
- Metadata: author, created, modified, plus a bounded `notes` column on the local
  SQLite index (additive in-place upgrade; not a server migration).

## Limits

- **Live Tesseract was never run.** Both the executor and the audit host lack the
  binary; OCR is proven against the executable-stub protocol (argument shape,
  rlimits, wall timeout, group reap, language probe, scratch-file mode), not
  against real recognition quality. This is recorded in the card and stands as
  the limit of AC «OCR works for scans».
- Two audit notes were fixed in the accepted source: the hard `pypdf` import and
  the un-reaped OCR process group.
- OCR depends on an external binary that is not installed by the Python package;
  deployment needs Tesseract with `rus` and `eng` traineddata or OCR degrades to
  `ocr_unavailable` notes.
