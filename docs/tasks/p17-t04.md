## Plan

1. Capabilities `onec.document.create.v1`, `onec.document.post.v1`, `onec.catalog.update.v1`, all off by default, require the separate write connection method.
2. Preview: typed payload validated against metadata, human-readable diff for updates, current object version (`DataVersion`) captured.
3. Approval via command ledger (per item); execute rechecks `DataVersion` (optimistic concurrency) and rights.
4. Idempotency: write a unique external reference (comment/attribute) and check for it before retrying a reconcile; timeouts → `unknown` + reconcile query.
5. API `POST /api/v1/integrations/1c/command/preview|approve|execute`, `GET …/audit-log` (from audit events + commands).
