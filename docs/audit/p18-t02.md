## Delivered

Persistent tenant/owner pairing, independently compared fingerprint confirmation,
short-lived client certificate issuance, bounded outbound sessions, consent and
revocation epochs, digest-only durable replay state, and ranked company-root search
observations with path/page references. Local-only queries, paths, metadata and
content cannot use a cloud fallback. Migration `0133` creates the three connector
tables and registers the resource and four permissions.

The chat now offers a separately invoked search over already consented company
roots and renders only references outside model context. It rechecks actor,
workspace, owner, online device and roots; limits form bytes before parsing; and
uses the same final authorization/release fence as the business API. Snippets do
not enter the chat response or model context. Untrusted reference paths render as
text, without executable links or HTML.

Affected paths: `app/services/local_connector/`, connector models and bootstrap,
`app/api/v1/endpoints/files_connectors.py`, API/catalog/config wiring, chat Python,
template and JavaScript, migration `0133`, supported Docker/Uvicorn launch paths,
pinned dependency exports, deployment guards, route references and six focused
test files.
