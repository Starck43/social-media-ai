## Goal and acceptance

Allow users to connect selected local/cloud folders, find and analyze files,
open originals and delegate explicitly approved actions. Retain compact,
version-aware conclusions and activity history without mirroring originals.
Acceptance requires current owner/tenant/policy checks, explicit processing and
retention consent, safe original access and actions, bounded retention and
revocation, and the required local integration, real-condition and audit checks.
Membership alone is not sharing; local-only/company data must not enter cloud
processing. The current PR does not yet meet these acceptance criteria.
