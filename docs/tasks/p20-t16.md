## Scope and acceptance

Redesign the four Work surfaces (Today, chat, inbox, tasks) using the owner PDF as reference. Preserve the existing message styling, sidebar, page-specific headers, existing slate/cyan variables, two themes and backend/security contracts. Support desktop and mobile, functional internal navigation, task calendar and applicable charts. Use isolated mock data and mock all external writes; do not deploy or alter public data. Scenarios are outside the four Work entries; preserve links to existing scenario surfaces.

Verify representative states, buttons, links, calendar and charts using local mock fixtures on multiple viewport sizes and both themes. Report exact checks and limits; no production operations.

## Ownership and dependencies

Owner: notion-agent. Proposed branch `feat/p20-t16-work-redesign`, worktree `/data/social-p20-t16`. Scope: Work templates, existing static assets and focused offline fixture/tests; do not touch unrelated surfaces. The application currently requires Python 3.14 and PostgreSQL.
