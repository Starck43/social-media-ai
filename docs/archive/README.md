# Archive

History kept for traceability, not for current work. Nothing here is a current
contract or evidence for a new revision; the live documents are the ones routed
by [DOCS_INDEX](../DOCS_INDEX.md).

- `P12_T14_*`, `P12_FILE_WORKSPACE_VALIDATION`, `PILOT_SUPPORT`: closed review and
  validation reports; their outcomes live in `docs/audit/` and the phase plans.
- `IMPLEMENTATION_STATUS`: delivered-work index with no active priorities.
- `api-route-contract`: P11-T08 route inventory; [API](../platform/API.md) and
  `docs/generated/` own the current surface.
- `AGENT_TASKS`: legacy anchor redirect table for the split into
  [AGENT_TASKS_PLAN](../agent/AGENT_TASKS_PLAN.md) and
  [AGENT_TASKS_QUEUE](../agent/AGENT_TASKS_QUEUE.md).
- `OWNER_BOOTSTRAP_INVENTORY`, `SOURCE_IDENTITY_INVENTORY`: the two runbooks were
  merged into [OPERATOR_INVENTORIES](../platform/OPERATOR_INVENTORIES.md).
- `tasks/`: completed task cards whose ROADMAP row is closed and whose result is
  recorded in `docs/audit/`.

Do not add a document here while a live document still depends on it; fix the
link in the live document instead.
