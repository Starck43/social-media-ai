## Failures found and fixed

The first contract run reported 79 failures/68 passes before implementation
fixes. The tests exposed unbounded final/out-of-range requests, malformed IDs
and items, silent partial-result loss, raw provider errors, owner `0` and
provider overdelivery. A separate owner-mismatch regression now enforces the
selected market scope. Four duplicated category readers now share a bounded
normalization/error helper; legacy people/posts error behavior is unchanged.

Executing the admin handler (rather than merely inspecting its source) exposed
a missing `JSONResponse` import, now fixed. Older P8-T33 assertions were updated
to the exact new states (video/apps/market `mocked`, music `deferred`); the
unavailable-category assertions were not relaxed.
