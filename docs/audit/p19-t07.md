## Findings

1. **`retrieval.py` boundary predicate contradicts its docstring** — `filter_snippets_by_acl` and
   `assemble_llm_citations_context` keep snippets where `snippet_level >= allowed_level`, so the
   documented `cloud` call drops `local_only`/`company` items while a `local_only` call returns all
   three. Not fixed here: the task is test-only and the fix changes what a subscriber sees, so it is
   an owner decision. Registered as [P19-T09](p19-t09.md) with both options and the recommended one.
2. `workspace.py` remains at 55%: the uncovered lines are async ORM resolvers
   (`_resolve_*_context`, `snippet_rows`, `document_rows`, `resolve_context`) that need DB
   integration tests, not unit ones. The package gate holds without them; no separate card raised
   since nothing there is currently wrong.
