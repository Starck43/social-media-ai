## Change

verdict, 35% on premature UI edits, 25% on independent review, 23% on DB-setup
research. Five forked children re-sent 56–102k of inherited context 20–43 times.

Process guardrails now require: verdict-only audit with UI work in a separate
`task` lane; compact self-contained child handoffs instead of session forks;
one-time route preflight and no polling loops; a ~1M input / ~20-turn child cap;
DB scenarios from an exact command list on an isolated schema; per-role route
order (tests `tester` → `free-pi` → own model, audit `perch` → `free-pi` →
`auditor`); and auditor-owned merge/closeout with a registry-only executor
exception. The incident and corrected prompt shape are in
[PROMPT_EXAMPLES](../../process/PROMPT_EXAMPLES.md#anti-pattern-audit-plus-redesign).
