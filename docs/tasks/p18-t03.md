## Plan

1. New top-level package `local_connector/` with its own `pyproject` (separate distribution, no import of `app`).
2. Folder selection UI (tray + local page on `127.0.0.1` with random port and CSRF token); default exclusions (system, hidden, `.ssh`, keychains, browser profiles, `node_modules`), user exclusions.
3. Path safety: canonicalize, refuse symlinks/junctions leaving selected roots, case-insensitive handling on Windows/macOS.
4. Index in SQLite with FTS5 (R-17): files table (path hash, size, mtime, content hash, type), chunks with page/sheet anchors.
5. Watcher (`watchdog`) + periodic rescan; incremental by mtime/size/hash; deletion removes index entries.
6. Outbound session client implementing the [P18-T01](../audit/p18-t01.md) protocol; local status page.
