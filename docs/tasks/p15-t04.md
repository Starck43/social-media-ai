## Goal

One place to read all conversations with a contact.

## Baseline

- `/app/communications` workspace (P12-T04/T09) and evidence drawer (P12-T06).

## Plan

1. API `GET /api/v1/communication/inbox` (filters: channel, date range, read/unread, archived, contact), `GET …/inbox/threads/{id}`, `POST …/mark-read`, `POST …/archive`; delete = local hide, not provider delete.
2. Chronological thread view with channel badges and original links; unavailable originals shown as such.
3. Search: metadata only (subject, participants, dates, channels, direction). D3 answered
   2026-11-04 keeps content out of search, so this task ships no `tsvector` index and no
   language configuration; content search is a separate measured decision.
4. Extend `/app/communications` with inbox tabs; evidence drawer handoff to chat with `data_boundary` respected.
