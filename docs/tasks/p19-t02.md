### Independent audit corrections (P19-T02 PR #463)

Implementation at the current task branch includes the requested corrections; validation and acceptance are pending:

- Production drafting calls `chat_with_fallback` in the acting user's eligible model catalog, with the existing workspace budget preflight, personal dispatch and `document_draft` attempt-journal purpose. The budget projection adds captured, priced draft-purpose attempts without adding the journal to legacy chat/digest/job totals; this remains the established non-atomic legacy cap behavior, not the future all-path admission ledger.
- Provider output must be non-empty JSON matching a strict paragraph schema. Provider failure, exhausted budget, prompt-injection rejection, or malformed output fails before document persistence; no deterministic production synthesis remains.
- Provider transport/no-model and malformed structured-response failures map to a sanitized HTTP 503. Personal budget/admission gates, permission failures and request cancellation preserve their existing exception behavior.
- Contact context uses only tenant-scoped `contact.VIEW` authorized display name and preferred/last channel. It has no invented boundary or citation metadata. Knowledge snippets retain boundary checks and are restricted to source-readable ACLs before copying into the broadly source-readable document body.
- Automatic support/citation marking accepts only an exact normalized excerpt quote; paraphrases, mixed claims and unrelated citations remain highlighted for review. JSON-Schema properties without `required` are optional. Symbol currency amounts such as `100 ₽`, `$100` and `€100` trigger human review.
- Added regressions cover the typed production pipeline seam, failure/no-persistence, budget exhaustion/unresolved journal evidence, contact projection, narrower snippet ACL, negation laundering, optional variables, and currency-symbol flags. Exact tested SHA and test evidence will be recorded after the delegated run.
