# P4-T02 — notification recipients, per-user read state and lifecycle

**Verdict:** ACCEPT · 2026-10-27 · independent acceptance by OpenCode —
implemented inside PR #246, accepted at head `898f904b`, integrated into dev
as merge `4e74318c` together with migrations 0113–0116.

## Scope accepted

`notifications` stays the immutable event row; per-user read state moves to
`notification_receipts` (read/dismiss/snooze per recipient), notification
`severity` is added, addressed delivery targets real users, and the bell/admin
projection reads receipts instead of one shared workspace flag. Admin
mark-read is removed; the legacy manager reads remain as an archive path.
Recipient recheck happens at navigation, bell and open — stale grants never
render.
