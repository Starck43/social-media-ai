## Goal

Extract searchable text from PDF, DOCX, XLSX, TXT, MD and scanned documents.

## Baseline

- P12-T12 bounded plain-text read rules (PR #327) for comparable limits.

## Plan

1. Extractors: `pypdf` (page anchors), `python-docx` (paragraph anchors), `openpyxl` read-only (sheet/cell anchors), text/markdown with encoding detection.
2. OCR via Tesseract (`rus+eng`) for image-only PDF pages/images, run in a subprocess with CPU time, memory and page limits.
3. Metadata: author, created, modified (from file and document properties).
4. Per-file size/time limits; failures recorded as extraction notes, never crash the indexer.
